# SVPG2023 / LANE 答辩展示版说明

## 1. 项目一句话概括

本项目基于原始 SVPG 仓库，构建了一个面向自动驾驶小车的强化学习实验平台，用于在四种典型道路场景中，对比基础算法与改进算法的控制效果和鲁棒性表现。

## 2. 项目背景

原始仓库来自论文 **Spiking Variational Policy Gradient for Brain Inspired Reinforcement Learning**，主要研究脑启发式强化学习中的脉冲策略网络。

在此基础上，本项目将原先偏通用的任务入口改造成了面向 `highway_env` 的小车车道驾驶任务，重点围绕以下目标展开：

- 在统一平台下训练基础算法与改进算法
- 支持多场景自动驾驶控制任务
- 输出可直接用于论文与答辩展示的权重、日志、视频和对比报告

## 3. 研究目标

本项目希望回答的问题可以概括为：

- 脑启发式脉冲策略网络能否在自动驾驶小车任务中稳定工作
- 相较基础训练流程，改进训练策略是否能提高场景适应性与鲁棒性
- 在执行器故障、输入噪声等干扰下，改进算法是否更稳定

## 4. 任务设置

当前主实验包含四种道路场景：

| 场景 | 含义 |
|---|---|
| `highway_standard` | 直道，标准车流 |
| `highway_dense` | 直道，高密度车流 |
| `merge` | 匝道汇入 |
| `roundabout` | 环岛 |

这些场景覆盖了：

- 基础跟车与换道能力
- 高密度交通下的稳定决策能力
- 汇入主路时的时机判断能力
- 环岛场景下的连续控制能力

## 5. 方法设计

项目中对比了两套训练方案：

### 5.1 基础算法 `base / baseline`

基础算法保留了原始 SVPG 风格的训练骨架，特点是：

- 训练流程相对直接
- 主要按验证回报选择最优模型
- 适合作为对照组和复现实验基线

### 5.2 改进算法 `ours`

改进算法在训练稳定性和场景适应性上做了增强，主要包括：

- 引入 rollout buffer
- 引入 GAE 优势估计
- 支持 mini-batch PPO 更新
- 支持梯度裁剪
- 加入课程学习机制
- 支持 warm start 热启动
- 针对车道场景加入自动稳定化超参数策略
- 综合成功率、碰撞率、速度和回报选择最优权重

## 6. 项目创新点

如果从答辩角度概括，可以把当前项目的工作亮点总结为：

1. 将原始脑启发式强化学习仓库改造成面向自动驾驶小车的多场景实验平台。
2. 在四种典型道路场景下统一开展基础算法与改进算法对比实验。
3. 设计了更适合车道场景的训练增强策略，包括 GAE、课程学习、warm start 和稳定化超参数配置。
4. 建立了完整的实验产物管理体系，使权重、日志、视频、对比报告都能自动按算法和场景分类保存。
5. 建立了从训练、验证、视频展示到鲁棒性分析的一体化实验链路。

## 7. 系统运行流程

整个项目的主流程如下：

1. 训练脚本读取参数并创建实验名
2. 根据算法类别和场景创建输出目录
3. 构建 `highway_env` 小车环境
4. 构建 actor 与 critic 网络
5. 进行强化学习训练与验证
6. 在验证指标更优时保存最优权重
7. 训练结束后自动清理冗余 checkpoint，只保留最优模型
8. 使用最优权重进行录像测试、鲁棒性评估和实验对比

## 8. 实验产物组织方式

### 8.1 训练权重与日志

训练结果位于：

```text
LANE/training_runs/
  baseline/
  ours/
```

每类算法下再按场景划分，并继续细分为：

- `models/`：最优权重
- `logs/`：训练日志

### 8.2 测试视频

测试视频位于：

```text
LANE/video_logs_lane/
  base/
  ours/
```

每类算法下再按场景和时间戳分类，方便答辩时快速查找典型样例。

### 8.3 对比报告

自动生成的对比报告位于：

```text
LANE/comparison_reports/
```

通常包含：

- Markdown 报告
- CSV 表格
- 可进一步用于画图的数据文件

## 9. 最常用实验命令

进入工作目录：

```bash
cd LANE
```

训练基础算法：

```bash
python3 run_RL_base.py --model rwtaspk --road_scenario highway --traffic_level standard --ignore_checkpoint --skip_post_tests
```

训练改进算法：

```bash
python3 run_RL_ours.py --model rwtaspk --road_scenario merge --ignore_checkpoint
```

录制视频：

```bash
python3 test_video.py --road_scenario merge --checkpoint_kind ours
```

生成对比报告：

```bash
python3 compare_experiments.py --device cpu
```

做鲁棒性测试：

```bash
python3 test_robustness.py --device cpu --max_models 2
```
