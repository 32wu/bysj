# 方案E：基于PDF论文的奖励函数设计

## 一、方案概述

参考《智能汽车自主变道决策与规划控制问题研究_王梓.pdf》第2.2章的奖励函数设计，用理论基础更扎实的5项奖励函数完全替换原有的11项经验性奖励系统。

## 二、原方案 vs PDF方案对比

### 原方案（11项奖励）
```
R = w_survival*s1 + w_progress*s2 + w_speed*s3 + w_gap*s4 + w_overtake*s5
  - w_crash*s6 - w_offroad*s7 - w_lane*s8 - w_zigzag*s9 - w_risky*s10 - w_stop*s11
```

**问题：**
- 过于复杂，11项奖励相互耦合
- 缺乏理论支撑，更多是经验性迭代堆砌
- 维护成本高，难以调试
- 参数调优缺乏指导原则

### PDF方案（5项奖励）
```
Rtotal = cv*Rv + cc*Rc + cl*Rl + cd*Rd + ce*Re
```

**优势：**
- 理论基础扎实，来自学术论文系统性研究
- 结构清晰，每个组件有明确物理意义
- 可解释性强，对应具体驾驶行为目标
- 参数调优有据，论文给出具体设置方法

## 三、5项奖励函数详细设计

### 1. 速度奖励 Rv（公式2.13）

**目标：** 激励车辆保持在目标速度附近行驶

**公式：**
```python
vtolerance = max(vtarget - vmin, vmax - vtarget)
if v <= vmin or v >= vmax:
    Rv = -2.0
else:
    Rv = 1.0 - abs(v - vtarget) / vtolerance
```

**参数设置：**
- vmin = 20 m/s（最小速度）
- vmax = 40 m/s（最大速度）
- vtarget = 29-30 m/s（目标速度，根据traffic_level调整）

**特点：**
- 引入速度容忍度机制，减少速度抖动
- 超出范围给予强惩罚（-2.0）
- 在范围内根据偏差线性惩罚

### 2. 碰撞奖励 Rc（公式2.14）

**目标：** 确保驾驶安全，避免碰撞

**公式：**
```python
Rc = -5.0 if crashed else 0.0
```

**特点：**
- 简单明确，碰撞给予强惩罚
- 权重系数cc=5.0，使总惩罚达到-25.0
- 与其他奖励相比，碰撞惩罚最高

### 3. 车道保持奖励 Rl（公式2.15）

**目标：** 激励车辆在车道中心附近行驶

**公式：**
```python
lateral_deviation = abs(ego_position_y - lane_center_y)
k, d = 0.5, 3.5
Rl = 1.0 if lateral_deviation <= k * d else 0.0
```

**参数设置：**
- k = 0.5（偏差系数）
- d = 3.5（车道宽度相关）
- 阈值 = k * d = 1.75m

**特点：**
- 显式计算与车道中心的横向偏差
- 二值奖励，在阈值内为1，超出为0
- 降低事故风险，提高行驶稳定性

### 4. 变道奖励 Rd（公式2.16）

**目标：** 鼓励合理变道，惩罚不必要变道

**公式：**
```python
if lane_changed:
    condition1 = v < vtarget  # 当前速度低于目标速度
    condition2 = adjacent_lane_avg_speed >= v + 10.0  # 相邻车道速度高10+
    if condition1 and condition2:
        Rd = 1.0   # 合理变道 (RC)
    else:
        Rd = -0.5  # 不合理变道 (UC)
else:
    Rd = 0.0  # 无变道 (NC)
```

**合理变道标准（PDF 2.2.3节）：**
1. 当前速度低于目标速度
2. 相邻车道平均速度至少比自车高10个单位

**特点：**
- 明确的合理性判断标准
- 减少不必要的变道行为
- 提高驾驶效率和安全性

### 5. 动作稳定性奖励 Re（公式2.17）

**目标：** 激励车辆保持稳定的动作序列

**公式：**
```python
lambda_decay = 0.05  # 衰减系数
if action_changed:
    Re = -exp(-lambda_decay * step_num)
else:
    Re = 0.0
```

**参数设置：**
- λ = 0.05（PDF建议值）
- 随时间指数衰减

**特点：**
- 惩罚频繁的动作切换
- 衰减机制平衡稳定性和响应性
- 确保高效、稳定的驾驶策略

## 四、权重系数设置

参考PDF表2.3，根据traffic_level调整：

| 参数 | dense | standard | light | 说明 |
|------|-------|----------|-------|------|
| cv   | 0.5   | 0.5      | 0.6   | 速度奖励权重 |
| cc   | 5.0   | 5.0      | 5.0   | 碰撞奖励权重 |
| cl   | 0.1   | 0.1      | 0.08  | 车道保持权重 |
| cd   | 0.5   | 0.5      | 0.4   | 变道奖励权重 |
| ce   | 2.0   | 2.0      | 1.5   | 动作稳定性权重 |
