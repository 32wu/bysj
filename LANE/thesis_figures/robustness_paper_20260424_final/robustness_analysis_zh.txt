图3给出了动作失效条件下的鲁棒性测试结果。总体来看，随着 failure rate 从 0 增大到 0.5，baseline 与本文方法的成功率均呈下降趋势，碰撞率则相应上升，说明执行器失效会直接削弱车辆的轨迹控制能力和避碰能力。然而，在两个交通密度场景中，本文方法均表现出更稳定的性能退化曲线。

在 highway-standard 场景中，本文方法在全部动作失效档位下均取得更高成功率和更低碰撞率。无扰动时，本文方法成功率为 82.70%，高于 baseline 的 78.67%，碰撞率则由 baseline 的 21.33% 降至 6.35%。当 failure rate 增大到 0.5 时，baseline 成功率下降至 30.80%，碰撞率升至 67.10%；本文方法仍保持 38.10% 的成功率，碰撞率为 49.80%。这表明在标准交通密度下，本文方法不仅在正常条件下具有更高的安全性，而且在动作失效逐步加重时仍能保留更好的任务完成能力。

在 highway-dense 场景中，动作失效带来的性能下降更加明显，但本文方法的优势更为稳定。无扰动时，本文方法成功率为 76.60%，显著高于 baseline 的 55.57%，碰撞率为 17.17%，低于 baseline 的 31.11%。在最强动作失效条件 failure rate = 0.5 下，baseline 成功率降至 12.40%，碰撞率达到 80.60%；本文方法成功率仍为 29.60%，碰撞率为 66.10%。说明在高密交通环境中，本文方法能够更好地应对动作执行不确定性，尤其是在车辆交互更加频繁、决策容错空间更小的情况下，仍能维持较低碰撞风险。

图4展示了输入高斯噪声扰动下的鲁棒性曲线。最新结果显示，输入噪声对策略性能具有明显影响：随着 input noise 从 0 增大到 0.20，两种方法在两个场景中的成功率均下降，碰撞率均上升。这说明观测扰动会削弱策略对道路状态和周围车辆状态的判断能力，从而影响安全决策。

在 highway-standard 场景中，baseline 的成功率从 78.67% 下降到 43.80%，碰撞率从 21.33% 上升到 55.70%；本文方法的成功率从 82.70% 下降到 57.20%，碰撞率从 6.35% 上升到 32.60%。可以看到，在所有输入噪声档位下，本文方法均保持更高成功率和更低碰撞率，尤其在 input noise = 0.20 时仍较 baseline 高出 13.40 个百分点的成功率，并降低 23.10 个百分点的碰撞率。

在 highway-dense 场景中，baseline 的成功率由 55.57% 降至 24.70%，碰撞率由 31.11% 升至 66.60%；本文方法的成功率由 76.60% 降至 40.90%，碰撞率由 17.17% 升至 56.10%。虽然高密场景下输入噪声对两种方法均造成较大影响，但本文方法在全部噪声档位下仍保持领先，说明其学习到的策略对观测扰动具有更强的容忍能力。

图5展示了权重高斯噪声扰动下的鲁棒性结果。权重噪声直接作用于策略网络参数，因此可以反映模型对参数扰动和内部不确定性的敏感性。随着 weight noise 增大，两种方法整体均出现成功率下降、碰撞率上升的趋势，但本文方法在两个场景下仍保持更优的鲁棒性边界。

在 highway-standard 场景中，baseline 的成功率从 78.67% 下降到 44.40%，碰撞率从 21.33% 上升到 54.80%；本文方法的成功率从 82.70% 下降到 53.80%，碰撞率从 6.35% 上升到 38.80%。在 weight noise = 0.10 的强扰动条件下，本文方法仍比 baseline 高 9.40 个百分点的成功率，并降低 16.00 个百分点的碰撞率。这表明本文方法在标准交通环境中对参数扰动具有更好的容错能力。

在 highway-dense 场景中，权重噪声对两种方法的影响更加剧烈。baseline 成功率从 55.57% 下降到 22.60%，碰撞率从 31.11% 上升到 72.40%；本文方法成功率从 76.60% 下降到 39.20%，碰撞率从 17.17% 上升到 60.80%。虽然本文方法同样出现明显退化，但在全部权重噪声档位下均优于 baseline，特别是在 weight noise = 0.10 时仍保持 16.60 个百分点的成功率优势和 11.60 个百分点的碰撞率优势。

综合三类扰动结果可以看出，本文方法在动作失效、输入噪声和权重噪声三种鲁棒性测试中均表现出相对 baseline 更平滑的性能退化趋势。尤其在 highway-dense 场景中，本文方法在高交通密度和强扰动叠加的情况下仍能维持更高成功率和更低碰撞率，说明其策略具有更好的复杂交互适应能力。与此同时，三类曲线也表明，当扰动强度持续增大时，两种方法均不可避免地出现性能下降，其中输入噪声和权重噪声会同时削弱任务完成能力和安全性。因此，后续工作可以进一步考虑更强的观测扰动建模、参数扰动正则化以及多源不确定性训练，以提升极端扰动条件下的鲁棒性上限。
